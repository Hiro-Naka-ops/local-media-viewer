# Local Media Viewer

Windows 11向けの完全ローカル画像・動画ビューワーです。PythonとPySide6で動作し、サーバーやインターネット接続は不要です。表示フィルターは元ファイルを変更しません。
ウィンドウフィットや縮小ズーム時はLanczos方式、拡大ズーム時はBicubic方式で表示用画像を再サンプリングし、網点のモアレと拡大時のブロック状表示を抑えます。

## 主な操作

- ホイール: 前後の画像・動画
- ホイールチルト（左右傾け）: 右へ傾けて次へ、左へ傾けて前へ
- サイドボタン: 「進む」で次へ、「戻る」で前へ
- Ctrl + ホイール: ズーム
- 左クリック: 原寸／ウィンドウに合わせる
- ホイールクリック: 全画面表示／解除
- メニューバー: 「ファイル」「表示」「見開き」「お気に入り」「ウィンドウ」（下記「メニュー」参照）
- ツールバー: 「前へ」「次へ」（動画のときは再生操作も）
- `Ctrl+O`: ファイルを開く / `Ctrl+Shift+O`: フォルダを開く
- 右クリック: お気に入り登録、フィット／原寸、全画面表示、各オプションの切り替え（動画のときは再生・停止・ミュートも）
- 動画を左クリック: 再生／一時停止
- 動画下端へカーソルを移動: 再生位置スライダーを表示
- 動画下部の半透明スライダー: 透明時も固定領域を維持して描画サイズを変えず、任意位置へ移動して現在時間／総時間を表示
- カーソルが動画下端から離れる: 約5秒後に操作欄をフェードアウト
- 動画: 終端まで再生すると先頭から自動的にリピート
- 動画上でCtrl + ホイール: 音量を5ずつ調整
- ツールバーの動画操作（動画を表示しているときだけ出ます）:
  「▶ 再生／❚❚ 一時停止」「■ 停止」（先頭に戻して止める）「ミュート」、音量スライダー（0～100）
- ドラッグ: ズーム中の表示位置を移動
- Esc: 全画面解除
- F: 右側フィルターパネルを開閉
- 「表示」→「フィルムストリップ」: 下部サムネイル一覧を開閉
- 下部サムネイルをクリック: その画像・動画へ直接移動
- 下部サムネイル上でホイール: フィルムストリップを左右へスクロール
- 十字キー: `←` / `↑` で前のメディア、`→` / `↓` で次のメディアを表示
- `Space`: ウィンドウにフィット／原寸表示を切り替え
- `Enter`: 全画面表示／解除（テンキーのEnterにも対応）
- フィルターをドラッグ: 約20段階の目盛り単位で調整（初期値付近では初期値へ吸着）
- Ctrl + フィルターをドラッグ: 1単位で自由調整

チルトの送られ方はマウスによって異なります。水平ホイールとして送るマウスと、サイドボタン（戻る／進む）として送るマウスがあり、どちらでもページを送れます。

全画面ではメニューバー、ツールバー、フィルター、ステータスを隠し、画像または動画だけを表示します。
フィルターの初期値は、明るさ `0`、コントラスト `0`、ガンマ `100`、色相 `0` です。
各スライダーでは初期値の目盛りを、長いオレンジ色の線で表示します。

先頭または末尾でさらにホイールを回した場合、隣に画像・動画を含むフォルダが無ければ通知は出さず、表示中の画像をそのまま表示し続けます。

## お気に入り

メニューバーの「お気に入り」→「お気に入りに登録」、または画像・動画の上で右クリックして
「お気に入りに登録」を選ぶと、表示中のフォルダをお気に入りへ追加します。
登録したお気に入りは「お気に入り」メニューの登録項目の下に、登録した時点の表示画像から作った
サムネイルとフォルダ名で並びます。メニューバーは全画面表示の間は隠れるため、お気に入りも同時に隠れます。

サムネイルは登録時点の画像で固定し、その後フォルダ内を移動しても変わりません。
同じフォルダを何度でも登録できます。表示中の画像を変えてから登録すれば、同じフォルダに対して
別々のサムネイルと戻り先を持つ項目が並びます。

項目が10件を超えるとメニューの高さを制限し、はみ出した分はホイールでスクロールします。
多段（複数列）には折り返しません。

- 「お気に入り」メニュー: 登録した項目の一覧を表示（未登録のときは「お気に入りはありません」）
- 項目をクリック: 登録時に表示していた画像へ戻る（消えている場合はフォルダの先頭）
- 項目を右クリック: その項目の解除、またはフォルダ分けのメニューを表示

### お気に入りのフォルダ分け

項目を右クリックして「フォルダへ移動」を選ぶと、お気に入りをフォルダにまとめられます。

- 「新しいフォルダ…」: 名前を入力して新しいフォルダを作り、その項目を移動
- 既存のフォルダ名: そのフォルダへ移動
- 「（フォルダなし）」: フォルダから出して一覧の直下へ戻す

フォルダはメニューの先頭に `名前 (件数)` の形でサブメニューとして並び、その下にフォルダ未所属の項目が続きます。
フォルダの中身が空になると、そのフォルダは一覧から消えます。

お気に入りはサムネイルとフォルダ分けを含めて `settings.json` に保存し、次回起動時に復元します。

現在位置の前後3画像はバックグラウンドで先読みします。先読み対象は周辺だけに限定し、フォルダ移動時には不要になったキャッシュを解放します。
画像と兄弟フォルダの並び順は「並び順」から選べます（初期値はファイル・フォルダ名の昇順）。
アニメーション画像は高精度タイマーで再生し、表示済みフレームを最大128 MBまで再利用します。

フィルター・エフェクト・見開きのいずれも使っていない静止画は、デコードした画像をそのまま画面へ渡します（画像処理ライブラリを経由しません）。
下部サムネイル一覧はファイル数ぶんのウィジェットを作らず、画面内に見えている範囲だけを描画します。サムネイルのデコードはバックグラウンドで行うため、フォルダを開いた直後から操作できます。
これにより1500ファイルのフォルダを開く時間は約7.5秒から約0.04秒に、ページ送りは約120ミリ秒から約15ミリ秒になりました。

## ステータスバー

ウィンドウ下端に、左から順に「現在のページ番号 / 総数」と表示中ファイルのパスを表示します。
右端には表示中ファイルの**作成日時と更新日時**、そのすぐ左に**現在の並び順アイコン**を表示します。

| アイコン | 並び順 |
| --- | --- |
| 横棒 | ファイル・フォルダ名 |
| カレンダー | 作成日時 |
| 時計 | 更新日時 |
| ↑ / ↓ | 昇順 / 降順 |

アイコンにカーソルを合わせると「並び順: 作成日時（昇順）」のように文字でも確認できます。

- 見開き表示のときは、パスとして表示している側（ページ番号の左側）のファイルの日時を出します
- 全画面表示の間はメニューバー・ツールバーとともにステータスバーごと隠れます
- 右端の日時は常設表示のため、「お気に入りに登録しました」などの一時メッセージでは消えません

## メニュー

上部はメニューバー（ファイル／表示／見開き／お気に入り／ウィンドウ）と、ページ送りだけの細いツールバーの2段です。
オプションはメニューバーと画像・動画上の右クリックメニューのどちらからでも切り替えられます。
どちらも同じ項目で、状態は連動します。

| メニュー | 項目 |
| --- | --- |
| ファイル | ファイルを開く… / フォルダを開く… / 終了 |
| 表示 | フィット／原寸 / フィルムストリップ・フィルター / エフェクト・並び順・パン位置 / 言語 / Language |
| 見開き | 見開き表示・右送り・表紙・ページをずらす |
| お気に入り | お気に入りに登録 / 登録した項目の一覧 |
| ウィンドウ | 全画面表示・常に手前に表示 / 最大化・画面の左半分・右半分・中央 / 次のディスプレイへ移動 |

右クリックメニューには、お気に入りに登録・フィット／原寸・全画面表示（動画のときは再生／一時停止・停止・ミュートも）と、
表示・見開きの各オプションが入ります。全画面ではメニューバーとツールバーが隠れるため、
右クリックだけで全画面を抜けられるようにしています。
言語は一度決めれば変えないものなので、「表示」メニューにだけ置いています。

「ウィンドウ」メニューの補足:

- 常に手前に表示: 他のアプリより前に出し続けます。オン／オフは `settings.json` に保存します
- 左半分・右半分: タイトルバーを含めたウィンドウ全体を、タスクバーを除いた画面のちょうど半分に合わせます
- 最大化や全画面のときに配置を選ぶと、先に通常表示へ戻してから配置します
- 次のディスプレイへ移動: 画面の大きさに合わせて同じ相対位置・大きさで移します。
  最大化・全画面だった場合は移動先でも同じ状態に戻します。ディスプレイが1台のときは選べません

| 項目 | 内容 |
| --- | --- |
| フィルムストリップ | 下部サムネイル一覧の表示切り替え |
| フィルター | 右側フィルターパネルの表示切り替え |
| エフェクト | サブメニューから表示エフェクトを選ぶ |
| 並び順 | サブメニューから並べ替えの基準と昇順・降順を選ぶ |
| パン位置を毎回初期化する | 別の画像に移るたびに、表示位置を上端・左右中央へ戻す（初期値: オン） |
| 見開き表示（2ページ） | 2ページを並べて表示 |
| 見開きを右送りにする | 見開きの並び順（オンで1ページ目が右） |
| 1ページ目を表紙として単独表示 | フォルダの1枚目を見開きにせず単独で表示（初期値オン） |
| 見開きページをずらす | 見開きの組み合わせを1ページ分ずらす |

拡大表示や原寸表示でドラッグして動かした表示位置を「パン位置」と呼びます。
このオプションがオフのときはパン位置を固定し、前の画像で動かした位置のまま次の画像を表示します。
オンにすると、別の画像に移るたびに上下は一番上・左右は中央へ戻します。

## 表示言語

「表示」→「言語 / Language」から、日本語・English・简体中文・한국어 を選べます。
初期値は「システムに合わせる」で、Windows の表示言語に合わせます（対応していない言語なら英語）。
切り替えるとその場で全体の表示が変わり、再起動は不要です。選んだ言語は `settings.json` に保存します。
メニュー名にはどの言語でも「Language」を併記するので、読めない言語になっても戻せます。

## エフェクト

「エフェクト」を選ぶとサブメニューが開き、表示エフェクトを1つ選べます。
フィルターと同じく表示用の加工で、元ファイルは変更しません。

| 項目 | 内容 |
| --- | --- |
| なし | 加工しない（初期値） |
| モノクロ | 明暗だけを残して白黒にする |
| セピア | 全体を褐色に寄せる |
| 線の色を変える | 黒を任意の色に置き換える。白はそのまま残すので、線画の線だけを変色できる |
| 線の色を選ぶ… | 「線の色を変える」で使う色を選ぶ。選ぶと同時にこのエフェクトへ切り替わる |

エフェクトはフィルターを適用した後に掛けます。中間調は黒側の色と白側の色の間に割り当てるため、
線画の濃淡は保たれます。

## 並び順

フォルダ内の画像の表示順と、「前へ」「次へ」でフォルダの端を越えるときの移動先を決めます。
右クリックまたはメニューバーの「表示」から「並び順」を選びます。

| 項目 | 内容 |
| --- | --- |
| ファイル・フォルダ名 | Windowsの論理的な名前順（数字を数値として扱う順序）。初期値 |
| 作成日時 | ファイル・フォルダが作られた日時順 |
| 更新日時 | 最後に更新された日時順 |
| 降順 | オンにすると逆順にする（初期値オフ＝昇順） |

- 基準と昇順・降順は独立して選べるので、組み合わせは6通りです
- **並び順を変えても、表示中の画像はそのまま表示し続けます**。並べ替えで位置が変わるため、
  位置ではなくファイルそのものを追いかけます
- 日時が同じファイルどうしは名前順で並びます。まとめてコピーしたファイルは日時が揃うことが多いためです
- 兄弟フォルダの「前・次」も同じ並び順に従います。降順にすると前後が入れ替わります
- 並び順を変えると、見開きの組み方はそのフォルダの先頭から数え直します

## 見開き表示

2ページを1枚に合成して表示します。見開きで1枚の絵を描いている作品のために、
2ページの間には隙間を入れず、高さの違うページは高い方に合わせて拡大・縮小してから
隙間なく連結します。

- 見開き中はホイールや十字キーで**2ページ単位**で進みます
- 「見開きを右送りにする」がオンのとき、1ページ目が右・2ページ目が左に並びます（日本の書籍向け）。
  オフにすると左右が入れ替わります
- 「1ページ目を表紙として単独表示」がオンのとき（初期値）、フォルダの1枚目は見開きにせず単独で表示し、
  2枚目から「2-3」「4-5」と組みます。表紙が1枚で始まる本に合わせた並びです。
  オフにすると1枚目から「1-2」「3-4」と組みます
- **フォルダを移動すると見開きの組み方は毎回そのフォルダの先頭から数え直します**。
  1冊ごとに独立して扱うため、前のフォルダのずれを引きずって新しい表紙が中身と組まれることはありません
- 見開きをオンにしたページが1ページ目になります。以降の組み合わせはその位置を基準に決まります
- 組み合わせがずれているときは「**見開きページをずらす**」を選ぶと、1ページ分ずれます。
  右側（奥側）のページがそのまま残り、その相方だけが入れ替わります（「2-3」→「3-4」）。
  ずらした組み方はそのフォルダを見ている間ずっと続きます
- 最後が1ページ余る場合や、動画・アニメーション画像を含む場合は、そのページだけ単独で表示します

## 対応形式

- 画像: JPG、PNG、BMP、GIF、WebP、TIFF
- 動画: MP4、WebM、MOV、AVI、MKV、M4V

動画の再生可否はWindowsとQt Multimediaが利用できるコーデックに依存します。表示フィルターは画像とアニメーション画像へ適用し、動画には初期版では適用しません。

## 起動

```cmd
set PYTHONPATH=src
python -m local_media_viewer
```

設定は `%LOCALAPPDATA%\LocalMediaViewer\settings.json` に保存します。
表示オプション（表示位置の復帰・見開き・送り方向・表紙の単独表示・見開きのずらし位置・並び順）も併せて保存し、次回起動時に復元します。
前回の続きから起動したときは、そのフォルダを閉じたときの見開きの組み方をそのまま復元します。
終了時のウィンドウ位置とサイズも保存し、次回起動時に復元します。起動引数で画像ファイルが渡された場合は、その画像を前回表示ファイルより優先して開きます。レジストリ操作やファイル関連付けの登録機能は提供しません。

## Windows EXEの作成

```cmd
python -m PyInstaller --noconfirm --clean --onefile --windowed --name "Local-Media-Viewer" --icon "assets/icon.ico" --paths "src" --exclude-module "numpy" "run_viewer.pyw"
```

アイコンは `assets/icon.ico`（16〜256pxを内包）で、元データは `assets/icon.svg` です。

`dist` には単体EXEが生成されます。EXEはGitへコミットせず、GitHub Releasesへ添付します。
ビルドではアプリが使用しないNumPyを除外し、単体EXEの容量を抑えます。Qtと動画再生部品は機能上必要なため同梱します。

## Mac版（.app）の作成

Mac 用のアプリは Mac 上でしかビルドできないため、GitHub Actions の macOS 環境でビルドします（手元に Mac がなくても作れます）。

1. GitHub のリポジトリページで **Actions** → **Build macOS app** → **Run workflow** を押す
2. 数分で完了したら、実行結果の **Artifacts** から自分の Mac に合うものをダウンロードする
   - `Local-Media-Viewer-macOS-arm64`: Apple シリコン（M1 以降）
   - `Local-Media-Viewer-macOS-x86_64`: Intel Mac
   - どちらか分からないときは、Apple メニュー →「この Mac について」の「チップ」を確認します
3. ダウンロードした zip の中にもう1つ zip があるので、それも展開すると `Local Media Viewer.app` が出てきます。
   「アプリケーション」フォルダへ移します

Mac が手元にあれば、`sh scripts/build_mac.sh` で同じものを `dist/` に作れます（Python 3.11〜3.13 が必要）。

### 初回の起動

Apple の署名をしていない自分用のアプリなので、最初の1回だけ macOS に止められます。

1. `Local Media Viewer.app` をダブルクリックする（「開けません」と出たら「完了」で閉じる）
2. システム設定 →「プライバシーとセキュリティ」を開き、下の方の「このまま開く」を押す
3. 確認が出たら「開く」を押す。以降は普通に起動できます

ターミナルを使う場合は `xattr -dr com.apple.quarantine "/Applications/Local Media Viewer.app"` でも同じです。

### Mac での違い

- メニューは画面最上部の Mac のメニューバーに入り、「終了」はアプリ名のメニューに移ります
- ショートカットの Ctrl は ⌘ になります（⌘O でファイルを開く、⌘ + スクロールでズーム）
- トラックパッドは2本指で1回スワイプすると1ページ進みます（スワイプ後の慣性ではページを送りません）
- 設定は `~/Library/Application Support/LocalMediaViewer/settings.json` に保存します
