# みかんマーク

Local Media Viewer のアイコンに使っているみかんのマークです。ほかのプロジェクトでもそのまま使えます。

| ファイル | 用途 |
| --- | --- |
| `mikan.svg` | 黄色（`#FFE600`）のマーク。大きさを自由に変えられます |
| `mikan-mono.svg` | 単色版。色は `currentColor`（HTML に埋め込むと周りの文字色になり、CSS の `color` で変えられます） |
| `mikan-64.png` 〜 `mikan-1024.png` | 黄色の PNG（横幅 64 / 128 / 256 / 512 / 1024px、背景は透明） |

## デザイン

- Apple のリンゴと同じくらい単純な形です: 丸い実、上の小さなへた、実から離れた葉
- 単体ファイルはまっすぐ立った向きです。アプリのアイコンでは右へ 20 度傾けて使っています
- 色は1色だけなので、単色版はどんな背景色にも合わせられます

## 作り直すとき

形の定義は `scripts/mikan.py` の1か所だけにあり、アプリのアイコン（`scripts/make_icon.py`）もそこから作ります。

```sh
python scripts/mikan.py       # このフォルダのファイルを作り直す
python scripts/make_icon.py   # アプリのアイコンを作り直す
```
